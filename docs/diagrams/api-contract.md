# API Contract — v1 (Week 1)

Base URL: `http://localhost:8000/api/v1`

All endpoints return JSON. Responses use a consistent envelope where applicable
(`{"success": true, "data": ...}`) and the correct HTTP status codes.

Authentication: `Authorization: Bearer <JWT>`

## Auth — `/auth`

| Method | Path       | Body                                     | Success         | Errors                 | Auth    |
| ------ | ---------- | ---------------------------------------- | --------------- | ---------------------- | ------- |
| POST   | `/register`| `{email, password, full_name, role: student\|company}` | 201 User | 400 duplicate email    | Public  |
| POST   | `/login`   | `{email, password}`                      | 200 `{access_token, token_type: "bearer"}` | 401 invalid | Public |
| GET    | `/me`      | —                                        | 200 User        | 401 not authenticated  | Bearer  |

## Student — `/students` (role: student)

| Method | Path              | Body                                             | Success | Errors |
| ------ | ----------------- | ------------------------------------------------ | ------- | ------ |
| GET    | `/profile`        | —                                                | 200 profile | 404 |
| PATCH  | `/profile`        | `{bio?, education?, resume_url?, phone?}`        | 200 profile | 404 |
| GET    | `/skills`         | —                                                | 200 `[skill]` | |
| POST   | `/skills`         | `{name}`                                         | 201 skill | 400 duplicate |
| GET    | `/posts`          | query: `query`, `location`, `skill` (all optional) | 200 `[post]` | |
| POST   | `/applications`   | `{post_id, cover_note?}`                         | 201 application | 404 post, 400 closed/duplicate |
| GET    | `/applications`   | —                                                | 200 `[application]` | |

`post` shape: `{id, company_id, company_name, title, description, location,
internship_type, duration, stipend, is_open, posted_at, skills[]}`

## Company — `/companies` (role: company)

| Method | Path                             | Body                                    | Success | Errors |
| ------ | -------------------------------- | --------------------------------------- | ------- | ------ |
| GET    | `/profile`                       | —                                       | 200 profile | 404 |
| PATCH  | `/profile`                       | `{name?, industry?, website?, description?, location?}` | 200 | 404 |
| POST   | `/posts`                         | `{title, description, location?, internship_type?, duration?, stipend?, skills[]?}` | 201 post | 400 |
| GET    | `/posts`                         | —                                       | 200 `[post]` | |
| PATCH  | `/posts/{post_id}`               | `{title?, description?, is_open?, ...}` | 200 post | 404 |
| GET    | `/posts/{post_id}/applicants`    | —                                       | 200 `[applicant]` | 404 |
| PATCH  | `/applications/{application_id}/status` | `{status: applied\|shortlisted\|interview\|selected\|rejected}` | 200 | 404/403 |

`applicant` shape: `{id, student_id, student_name, email, status, cover_note,
applied_at, skills[]}`

## Admin — `/admin` (role: admin)

| Method | Path      | Success         | Errors |
| ------ | --------- | --------------- | ------ |
| GET    | `/users`  | 200 `[user]`    | 401/403 |
| GET    | `/posts`  | 200 `[post]`    | 401/403 |

## Health — `/health`

| Method | Path     | Success         |
| ------ | -------- | --------------- |
| GET    | `/health`| 200 `{status: "ok"}` |

Swagger UI is auto-generated by FastAPI at `http://localhost:8000/docs`.
